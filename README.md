# Gabriel Armando Sormin: Portfolio

Portfolio of a Marketing Data Analyst, with five case studies and three working app demos.

- `index.html`: portfolio page (case studies, skills, experience)
- `control-tower.html`: sales control dashboard demo (five-level hierarchy, pace-based status, escalations)
- `reward-claims.html`: reward claim approval demo (four roles, duplicate-invoice and program checks, audit trail)
- `formulation.html`: paint formulation and costing demo (versioned reformulation, QC checks, L*a*b* color match)

All data, formulas, prices, names and companies in these demos are fictional. The demos are new code written
for this portfolio and recreate how each tool works; they contain no code or data from any employer.

Plain HTML, CSS and JavaScript with no build step. To publish with GitHub Pages: push these files to a public
repository, then open Settings > Pages and deploy from the main branch, root folder.

Built with AI-assisted development.
